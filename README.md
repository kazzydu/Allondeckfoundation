# AllONDECK Foundation website

Static site for allondeckfoundation.org, deployed by Netlify on every push to `main`.

- `index.html`: the Foundation page.
- `foundation-report-itf-2026.html`: 2026 progress report.
- Donations use Flutterwave Checkout (public key only). Back a Player and the admin pages still live on allondeck.org.
- Editing rules: see the Foundation workspace's CLAUDE.md and documents/foundation-page-notes.md.
